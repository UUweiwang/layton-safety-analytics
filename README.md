
# Layton Construction Safety Analytics

An interactive safety analytics dashboard developed
as an academic team project.

## Project Overview

This project uses synthetic construction safety data
to explore workforce risk, hazard prevention,
and safety performance.

The dashboard was built using Python and Streamlit
to support data-driven safety management decisions.
